对数据处理
企业主体属性
基于企业名称和经营范围，最近一次发布工种，llm提取初步语义信息，
产出最多 3 个静态候选行业，个候选行业附一行原因
用一句自然语言概括静态主体倾向
不做最终裁决，只表达静态视角结论

- 企业招工行为
招工行为用于识别企业近期真实业务重心
- 每个工种：近 3 个月该工种在全部招聘中的占比，前10个就好
- 每个工种：近 3 个月该工种在全部招聘中的数量，前10个就好
- 总招聘数
- 3个月,发布工种列表（去重）
- 近期30天（去重）招工信息 最大20条，时间排序截断

llm 提取语义信息，用一句自然语言总结近 3 个月的招工画像
- 强调“主岗位 + 持续性 + 场景”
- `近3个月招聘持续且集中，主要围绕保安、保洁、维修岗位，场景偏小区和园区。

llm 再根据企业主体属性，结合企业招工行为 判定类标签每个企业只能输出 1 个行业标签
招工行为的权重更高点
